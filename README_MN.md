# Онлайн 2 тоглогчийн Tetris

## Онцлог
- 6 тэмдэгттэй өрөөний кодоор холбогдоно.
- Тоглогч 1 өрөө үүсгэнэ; тоглогч 2 кодоор нэгдэнэ.
- Тоглогч 1-ийн браузер тоглоомын үндсэн симуляцийг ажиллуулж, тоглогч 2-ын товчлуурын үйлдлийг серверээр дамжуулан авна.
- Талбар, оноо, шугам, хожил/ялагдлын төлөв хоёр талд шинэчлэгдэнэ.
- Socket.IO ашигладаг.

## Render дээр үнэгүй байрлуулах
1. GitHub-д шинэ repository үүсгэнэ.
2. Энэ хавтасны бүх файлыг repository-д оруулж push хийнэ.
3. https://render.com дээр бүртгүүлж Dashboard нээнэ.
4. **New → Blueprint** сонгоод GitHub repository-гоо холбоно.
5. `render.yaml`-ийг Render автоматаар уншиж Web Service үүсгэнэ. Free төлөвлөгөөг сонгоно.
6. Deploy дуусахад Render-ийн `https://....onrender.com` холбоос гарна. Хоёр тоглогч хоёулаа тэр холбоосыг нээнэ.
7. Нэг нь **Өрөө үүсгэх** дарж кодоо нөгөөдөө явуулна. Нөгөө нь кодоо оруулаад **Өрөөнд нэгдэх** дарна.

## Компьютер дээрээ турших
```bash
npm install
npm start
```
Дараа нь `http://localhost:3000` нээнэ.

## Тоглох
- Тоглогч 1: A/D хөдөлгөх, W эргүүлэх, S доош, Space унагах, C хадгалах.
- Тоглогч 2: ←/→ хөдөлгөх, ↑ эргүүлэх, ↓ доош, Enter унагах, Shift хадгалах.
- Бэлэн болохдоо өөрийн эхлүүлэх товчийг дарна.

## Үнэгүй Render-ийн анхаарах зүйл
Render-ийн Free web service 15 минут орчим оролтын урсгалгүй байвал унтарч, дараагийн холболтоор дахин асахдаа ойролцоогоор нэг минут авч болно. Үнэгүй хувилбар нь туршилт, хобби төсөлд тохиромжтой; тоглолтын үеэр идэвхтэй WebSocket холболт нь үйлчилгээг сэрүүн байлгадаг.
